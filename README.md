# 🚀 Mission 5: TypeScript Migration & Layered Architecture

기존 Express.js 기반의 프로젝트를 **TypeScript**로 마이그레이션하고, **Layered Architecture**를 적용하여 유지보수성과 확장성을 높인 프로젝트입니다.

## 🎯 미션 목표
*   **TypeScript 도입:** 정적 타입 검사를 통한 안정성 확보 및 개발 생산성 향상
*   **개발 환경 구축:** `tsconfig.json`, `nodemon`, `ts-node`를 활용한 효율적인 개발 환경 세팅
*   **아키텍처 개선 (심화):** 관심사의 분리를 위한 Controller-Service-Repository 계층 구조 적용

---

## 🛠️ 기술 스택 (Tech Stack)
*   **Language:** TypeScript
*   **Runtime:** Node.js
*   **Framework:** Express.js
*   **Dev Tools:** nodemon, ts-node
*   **Package Manager:** npm
